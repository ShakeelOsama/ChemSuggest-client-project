# ChemSuggest - Chemistry Learning Application

A comprehensive Flutter-based mobile application designed as an educational chemistry companion. The app provides users with detailed information about various chemicals, interactive quizzes, and an intuitive interface for learning chemistry concepts.

## 📱 Features

- **Chemical Database** - Extensive database of chemicals with detailed information
- **Interactive Quiz System** - 8 quiz categories with multiple-choice questions
- **Modern UI/UX** - Material Design 3 with dark/light theme support
- **Cross-Platform** - Supports Android, iOS, Web, Windows, Linux, and macOS
- **Theme Customization** - Light, Dark, and System theme modes
- **Comprehensive Navigation** - Bottom navigation with 4 main sections

## 🛠️ Technologies

- **Flutter** (SDK ^3.9.2)
- **Dart** Programming Language
- **Provider** - State Management
- **SharedPreferences** - Local Storage
- **Material Design 3** - UI Framework

## 📋 Requirements

- Flutter SDK 3.9.2 or higher
- Dart SDK
- Android Studio / VS Code
- Xcode (for iOS development)
- Android SDK (for Android development)

## 🚀 Getting Started

1. Clone the repository
2. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
